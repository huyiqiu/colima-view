# Repository instructions

Read `CONTRIBUTING.md` for the project layout, localization conventions, and verification commands.

## Commit attribution

For commits containing code or documentation materially authored with Codex, append this trailer to the commit message:

```text
Co-authored-by: Codex <codex@openai.com>
```

Preserve the human author's Git identity and any existing co-author trailers. Keep the Codex trailer in prepared squash commit messages so attribution survives merging. Add the trailer only when Codex contributed to the changes.

Apply this rule to future commits. Do not rewrite published history solely to add attribution unless the user explicitly requests it.
